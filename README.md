# Ashen accessories for Roblox (R6)

Procedurally built rigid accessories for the Roblox Marketplace in an archive visual kei / goth / grunge style,
fitted to Roblox's default R6 avatar. Every model is generated by a Python build script running Blender 5.2's `bpy`
module, then validated, baked to PBR textures and exported as a single-mesh FBX.

## Accessories

| Accessory | Type | Attachment | Folder |
| --- | --- | --- | --- |

Each folder holds `<Name>.fbx` (one mesh, one material, textures embedded), `textures/` (ColorMap 1024², NormalMap,
RoughnessMap and MetalnessMap 256²), the `.blend` scene, the `<Name>.json` build and validation report, preview
renders and a README with the Roblox setup values.

## Layout

- `!free.7z`: the original archive with the toolkit, earlier build scripts and the earlier finished models.
- `tools/`: toolkit extracted from the archive (`rbxkit.py`, `rbxgeo.py`, `rbxsdf.py`), `check_fbx.py`, and one
  `build_<item>.py` per accessory.
- `assets/<Name>/`: build output for each accessory.

## Rebuilding

The `bpy` 5.2 wheels need Python 3.13:

```sh
uv venv --python 3.13 /opt/rbxenv
uv pip install --python /opt/rbxenv/bin/python -r tools/requirements.txt
/opt/rbxenv/bin/python tools/build_<item>.py                     # writes assets/<Name>/
/opt/rbxenv/bin/python tools/check_fbx.py assets/<Name>/<Name>.fbx  # re-imports and checks the FBX
```

`DRY=1` prints the triangle tally, bounds and body clearance and exits; `LOOK=1` renders quick un-baked previews
into `.cache/`. The first run downloads Roblox's `LC_ClassicMale` reference FBX into `.cache/` and derives the R6
reference body from it.

## R6 fit

New build scripts call `K.use_rig('R6')`. The R6 reference body matches Roblox's R6 rig: a 2×2×1 torso, 1×2×1 limbs
and the classic 1.2-stud head centred 1.5 studs above the torso centre, with the rig's own attachment offsets
(`ATTACH_R6` in `tools/rbxkit.py`). The checks run against it: at most 4,000 triangles, a closed mesh, the strictest
Creator Hub size limits for the accessory type around its attachment, and no vertex inside the body. The archived
build scripts still default to the `LC_ClassicMale` mannequin they were made for.

## Using an accessory in Roblox Studio

1. Import `<Name>.fbx` with the 3D Importer, or let the Accessory Fitting Tool create the accessory with the
   accessory type from the item's README.
2. If you set it up by hand: the imported MeshPart becomes the `Handle` of an `Accessory`; add an `Attachment`
   named as in the item's README (for example `BodyBackAttachment`) at the listed Handle attachment position.
3. Add a `SurfaceAppearance` with the four maps from `textures/` if the importer did not pick up the embedded ones.
